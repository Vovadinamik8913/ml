```python
if n_pos < subsample_size / 2:
    n_neg = min(subsample_size - n_pos, len(neg_idx))
    if n_neg > 0:
        idx = np.concatenate([pos_idx, np.random.choice(neg_idx, n_neg, replace=False)])
    else:
        idx = pos_idx
```

**📖 Простыми словами:**  
**Случай 1: положительных примеров мало** (меньше половины от нужного размера выборки).

Берём **все положительные** примеры и дополняем их случайными отрицательными до нужного размера.

**Аналогия:**  
У вас есть 100 красных шаров (положительные) и 9900 синих (отрицательные). Вам нужно 1000 шаров для анализа.  
Вы берёте **все 100 красных** + **900 случайных синих**.

**🔬 Технически:**  
```
Условие: n_pos < 100000 (половина от subsample_size=200k)

Стратегия:
  1. Взять ВСЕ положительные: pos_idx (все n_pos штук)
  2. Взять случайные отрицательные: random_choice(neg_idx, n_neg)
     где n_neg = min(200000 - n_pos, len(neg_idx))
  
  3. Объединить: idx = [pos_idx, neg_sample]

Пример для target_2_8 (83 положительных):
  pos_idx: 83 примера (все)
  n_neg = min(200000 - 83, 749917) = 199917
  neg_sample: 199917 случайных отрицательных
  
  Итого: idx = 83 + 199917 = 200000 строк
  Баланс: 83 positive (0.04%) + 199917 negative (99.96%)
  
  ⚠️ Всё ещё дисбаланс, но хотя бы все positive сохранены!
```

---

```python
else:
    n_pos_sample = min(subsample_size // 2, n_pos)
```

**🔬 Технически:**  

```python
importance = model.feature_importances_
```

**📖 Простыми словами:**  
Получаем важность каждого признака — насколько модель использовала этот признак для предсказаний.

**🔬 Технически:**  
```
importance ∈ ℝ^(2444,) — массив важности для каждого признака

Как LightGBM вычисляет важность (по умолчанию 'gain'):
  importance[j] = Σ (gain от всех split'ов по признаку j)
  
  gain = уменьшение функции потерь после split'а
  
  Формально:
  gain = L(parent) - [L(left_child) + L(right_child)]
  
  где L — функция потерь (binary cross-entropy)
  
  Интерпретация:
  - importance[j] = 0 → признак никогда не использовался
  - importance[j] > 0 → признак использовался, чем больше — тем важнее
```

---

```python
top_idx = np.argsort(importance)[::-1][:k]
```

**📖 Простыми словами:**  
Сортируем признаки по важности (от большего к меньшему) и берём индексы топ-K.

**🔬 Технически:**  
```
np.argsort(importance) — индексы, которые отсортируют importance по возрастанию
[::-1] — разворачиваем, чтобы было по убыванию
[:k] — берём первые k индексов (топ-K)

Пример:
  importance = [0.5, 2.3, 0.1, 5.7, 1.2]
  np.argsort(importance) = [2, 0, 4, 1, 3]  # индексы по возрастанию
  np.argsort(importance)[::-1] = [3, 1, 4, 0, 2]  # по убыванию
  top_idx[:3] = [3, 1, 4]  # топ-3 признака
```

```
  y = y_t (750000,)
  cat_features = cat_feature_names
  k = 400 (TOP_K_FEATURES)
  subsample_size = адаптированный размер (2490–200000)

Возвращает:
  selected_features_dict[t] = список из 400 имён признаков
```

## 🔑 Ключевые идеи

### 1. Почему отдельный отбор для каждого таргета?

```
❌ ОБЩИЙ отбор (неправильно):
   Один список признаков для всех 41 таргетов
   → Теряем специфику каждого продукта

✅ ПЕРСОНАЛЬНЫЙ отбор (правильно):
   41 разных списков признаков
   → Каждый таргет получает свои лучшие признаки
```

**Пример:**

| Признак | Для кредитки | Для депозита |
|---------|--------------|--------------|
| `num_feature_credit_limit` | 🔴 Очень важен | ⚪ Не важен |
| `num_feature_balance` | ⚪ Средне | 🔴 Очень важен |
| `num_feature_age` | ⚪ Средне | 🔴 Очень важен |

---

### 2. Почему балансировка классов?

```
Без балансировки:
  Model: "99% клиентов не купили → предсказываю 0 всегда"
  Accuracy: 99% ✅
  AUC: 0.5 ❌ (случайное угадывание)

С балансировкой 50/50:
  Model: "Нельзя просто предсказывать 0 — нужно искать паттерны"
  Accuracy: 75% 
  AUC: 0.75+ ✅ (реальное качество)
```

### 4. Почему кэширование результатов?

```
41 таргет × 30 секунд = 1230 секунд = 20 минут

Без кэширования:
  Запуск 1: 20 минут ⏱️
  Запуск 2: 20 минут ⏱️
  Запуск 3: 20 минут ⏱️

С кэшированием:
  Запуск 1: 20 минут ⏱️ (отбор + сохранение)
  Запуск 2: 5 секунд ⚡ (загрузка из файла)
  Запуск 3: 5 секунд ⚡ (загрузка из файла)
```
